# Русский глоссарий (Russian Glossary)

Документ содержит основные термины, используемые в персональной редакции, чтобы унифицировать переводы агрегации моделей, маршрутизации, биллинга и интерфейса администратора.

## Основные понятия (Core Concepts)

| Китайский | Русский | Английский | Описание |
|-----------|---------|-----------|----------|
| 倍率 | Коэффициент | Ratio | Множитель для расчёта цен моделей и задач |
| 令牌 | Токен | Token | Учётные данные API или текстовая единица, обрабатываемая моделью |
| 渠道 | Канал | Channel | Канал доступа к вышестоящему API-провайдеру |
| 路由分组 | Группа маршрутизации | Route Group | Определяет маршрутизацию, доступные модели и коэффициент биллинга |
| 额度 | Квота | Quota | Квота кошелька администратора или API-токена |

## Модели и цены (Models and Pricing)

| Китайский | Русский | Английский | Описание |
|-----------|---------|-----------|----------|
| 提示 | Промпт | Prompt | Входные данные модели |
| 补全 | Дополнение | Completion | Выходные данные модели |
| 模型倍率 | Коэффициент модели | Model Ratio | Коэффициент тарификации модели |
| 固定价格 | Цена за вызов | Price per call | Фиксированная цена одного вызова |
| 按量计费 | Оплата по использованию | Pay-as-you-go | Расчёт по фактическому использованию |

## Учётная запись администратора (Administrator Account)

| Китайский | Русский | Английский | Описание |
|-----------|---------|-----------|----------|
| root 管理员 | Администратор root | Root Administrator | Единственный владелец панели в персональной редакции |
| 管理员 Session | Сеанс администратора | Administrator Session | Сеанс входа в панель администратора |
| API Token | API-токен | API Token | Учётные данные для вызовов Relay и задач |
| 安全证明 | Доказательство безопасности | Security Proof | Краткосрочное подтверждение для чувствительных операций, привязанное к сеансу |

## Управление каналами (Channel Management)

| Китайский | Русский | Английский | Описание |
|-----------|---------|-----------|----------|
| 密钥 | Ключ | Key | Ключ API или учётные данные вышестоящего канала |
| 优先级 | Приоритет | Priority | Приоритет выбора канала |
| 权重 | Вес | Weight | Вес балансировки нагрузки |
| 代理 | Прокси | Proxy | Адрес прокси-сервера |
| 模型映射 | Сопоставление модели | Model Mapping | Замена имени модели на имя вышестоящей модели |
| 厂商 | Поставщик | Vendor | Поставщик модели или API-сервиса |

## Биллинг (Billing)

| Китайский | Русский | Английский | Описание |
|-----------|---------|-----------|----------|
| 预扣 | Предварительное списание | Pre-consumption | Временное списание рассчитанной квоты перед вызовом |
| 结算 | Расчёт | Settlement | Корректировка по фактическому использованию |
| 退款 | Возврат | Refund | Возврат неиспользованной квоты после ошибки |
| 自动分组 | Автоматические группы | Auto Groups | Попытка групп маршрутизации в настроенном порядке |

## Рекомендации (Guidelines)

- **Группа маршрутизации (Route Group)** означает только маршрутизацию моделей и биллинг, а не уровень учётной записи и не права пользователя.
- **Цена модели (Model Price)** означает данные каталога и биллинга, а не цену пополнения, подписки или публичной продажи.
- Сохраняйте технические термины **Ratio**, **Token**, **API Token** и **Access Token**, когда этого требует контекст.
